## 产品介绍

快速，简单，优雅地一键启动 LoliaFRP 内网穿透。

Lolia-FRP 是一个基于 fatedier/frp 的开源反向代理项目，支持 TCP、UDP、HTTP 和 HTTPS 协议。

## 配置和使用说明

1. 访问 [隧道管理 - Lolia FRP](https://dash.lolia.link/dash/tunnel)，创建一个隧道；
2. 获取隧道 id 与节点 token
